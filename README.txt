# РІВНЕ БУКЕТИКИ — готовий статичний сайт

## Як запустити
1. Розпакуйте ZIP.
2. Відкрийте `index.html` у Chrome/Edge.
3. Сайт працює без сервера.

## ЛОГОТИП
Покладіть свій логотип у:
`assets/logo/logo.png`

Якщо файл називається інакше — відкрийте `settings.js` і змініть:
`logo: "assets/logo/logo.png"`

## ФОТО
Для кожної категорії є окрема папка:
- `photos/atlasni-strichky`
- `photos/3d-bukety`
- `photos/mylni-bukety`
- `photos/bukety-z-serdechok`
- `photos/boks-kosmetyky`
- `photos/boks-z-cukerkamy`
- `photos/solodki-bukety`

За замовчуванням картинка першого товару:
`1.jpg`

Щоб змінити картинку, найпростіше:
1. Покласти нове фото в потрібну папку.
2. Натиснути на сайті `⚙ Редактор`.
3. У полі «Фото / шлях до файлу» вписати, наприклад:
`photos/3d-bukety/2.jpg`
4. Натиснути «Зберегти зміни».

## ЦІНИ
На сайті натисніть `⚙ Редактор`, змініть ціну і натисніть «Зберегти зміни».
Зміни зберігаються у localStorage цього браузера.

Для зміни стартових цін назавжди відредагуйте `products.js`.

## МУЗИКА
Файл `Last Christmas` не включено до ZIP через авторські права.
Додайте свій легально отриманий файл:
`assets/music/last-christmas.mp3`
Потім натисніть `♫ Музика`.

Автовідтворення музики може блокувати браузер, тому на сайті є кнопка ручного запуску.

## ВАЖЛИВО
Це статичний сайт. Якщо ви відкриваєте його просто через `index.html`, він не завантажує фото з інтернету — тільки файли, які лежать у ZIP поруч із сайтом.

## ВИПРАВЛЕНО: ФОТО
Тепер сайт автоматично шукає в кожній папці:
1.jpg ... 12.jpg
1.jpeg ... 12.jpeg
1.png ... 12.png
1.webp ... 12.webp
і показує знайдені фото. Нічого в JavaScript міняти не потрібно.

## ВИПРАВЛЕНО: MP3
Додайте `assets/music/last-christmas.mp3` і натисніть кнопку `♫ Музика`.
Якщо браузер не дозволить відкрити файл напряму, кнопка запропонує вибрати MP3 з комп'ютера.


Ця версія: каталог фото без цін та без редактора. За замовленням та консультацією — Instagram.


## ФОТО НА GITHUB PAGES
На GitHub Pages сайт автоматично читає файли з папок `photos/...` через GitHub API.
Тому можна просто додавати фото в потрібну папку через GitHub — код міняти не потрібно.
Підтримуються JPG, JPEG, PNG та WEBP, назви можуть бути будь-які.
Після завантаження зачекайте 1–2 хвилини та оновіть сторінку.


КАТЕГОРІЇ: натисніть категорію, щоб відкрити галерею. Фото додавайте як 1.jpg, 2.jpg, 3.jpg... у відповідну папку photos.
